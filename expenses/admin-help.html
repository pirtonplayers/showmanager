Help

Pirton Players Expenses — Manager

Signing in

This app is manager-only — the account needs Manager switched on (Users tab) to get in at all. Same "Forgot password?" flow as the player app if needed.

Expenses

Defaults to unpaid expenses only — switch the filter to see paid ones too, or filter further by show or by name/email. Receipts open in a new tab (a dropdown if there's more than one attached to the same expense).

Delete removes a mistaken entry entirely. Export to Excel downloads whatever the current filters are showing.

Mark expenses as paid

Choose a person from the dropdown (only people with an outstanding balance are listed), tick which of their expenses you're paying — all ticked by default — and watch the running total. Untick anything you're not paying yet.

Submitting marks every ticked expense as paid and sends that person one email listing everything just paid and the total, whether it's one expense or several.

Reports

Three linked views — by show, by submitter, and a full detail table — all reflecting the same show / date range / paid-unpaid filters.

Export report downloads a three-sheet workbook matching whatever's currently filtered.

Shows

Add a show here to make it selectable in the player app. Untick Active to hide it from that dropdown without deleting it — past expenses against it are unaffected either way, including if you remove it entirely.

Users

Add a user creates a player's login with a temporary password you set and pass on — they're forced to choose their own on first sign-in.

Approved gates whether someone can submit expenses; Manager gives them access to this admin app. Delete permanently removes a login (their past expenses stay on record).

Sync manager permissions is a fix-it button — use it if a manager ever finds they can't view a receipt that should be visible to them (they'll also need to sign out and back in afterward to pick it up).

Settings

Expense notification emails — who's told whenever a player submits new expenses. Sender email — the "from" address on all outgoing emails; it has to already be a verified sender in Brevo or mail silently fails to send.

Storage shows how much space receipt photos are actually using — this project's on the pay-as-you-go plan, so there's no fixed quota, just cost.
