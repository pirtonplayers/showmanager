Settings

Users

Logins and access are managed in one place for every showmanager app now — open the portal → Users to add someone, grant Expenses admin access, or mark expenses access approved/unapproved.

Expense notification emails

Everyone on this list gets an email whenever a player submits a new expense (or registers). The submitter is separately emailed when their own expense is marked paid.

Sender email

The "from" address on both emails above (new-expense notifications and paid acknowledgements). Must be a sender already verified in Brevo — an unverified address will fail to send, or land in spam, rather than notify anyone. Leave blank to fall back to the SMTP_FROM secret set at deploy time.

Default link message

Pre-fills the message box on Users → Send link — still editable per person before it's sent, this just saves retyping the usual note each time.

Storage

Receipt photos only — this project is on the Blaze (pay-as-you-go) plan, so there's no fixed quota to run out of, just cost, which scales with how much is stored.
